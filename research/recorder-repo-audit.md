# Recorder repository audit

**Audited:** 2026-08-26 UTC  
**Scope:** current GitHub REST metadata and commit-pinned raw source at each default-branch HEAD. Dates below were checked against the audit clock; none is treated as future evidence. Official service pages and limited no-credential probes are identified separately.

## Evidence labels

- **Source-observed:** present in GitHub metadata/code/configuration or an official service page; not proof that the program runs.
- **Runtime-proven:** directly executed/probed during this audit, or evidenced by a linked completed GitHub Actions run. Proof is limited to the exact tested behavior.
- **Strict free-only:** no funded wallet, usage-priced operation/package, card, temporary trial, or metered paid dependency. A free claim is not automatically a no-meter guarantee.

## 1. `shaurya35/solana-realtime-indexer`

**Metadata/license.** Public, unarchived `main`; created 2026-07-11, pushed 2026-08-24; audit HEAD [`d7f510d`](https://github.com/shaurya35/solana-realtime-indexer/commit/d7f510dcc36a3b7635d4bf89ea1e911e5eb8ed98); 0 stars/forks/open issues at audit time; GitHub detects MIT and the repository contains a standard MIT file. [Repository API](https://api.github.com/repos/shaurya35/solana-realtime-indexer) · [tree API](https://api.github.com/repos/shaurya35/solana-realtime-indexer/git/trees/main?recursive=1) · [LICENSE](https://raw.githubusercontent.com/shaurya35/solana-realtime-indexer/d7f510dcc36a3b7635d4bf89ea1e911e5eb8ed98/LICENSE)

**Functionality—source-observed.** `capture` connects to Yellowstone gRPC, serializes each protobuf transaction update as base64 in JSONL, and flushes the output at completion. The replay datasource decodes those records and feeds the same transaction pipeline. Postgres writes events, trades, and a checkpoint in one transaction; failed batches are parked as dead letters. [capture.rs](https://raw.githubusercontent.com/shaurya35/solana-realtime-indexer/d7f510dcc36a3b7635d4bf89ea1e911e5eb8ed98/src/capture.rs) · [replay.rs](https://raw.githubusercontent.com/shaurya35/solana-realtime-indexer/d7f510dcc36a3b7635d4bf89ea1e911e5eb8ed98/src/datasources/replay.rs) · [writer.rs](https://raw.githubusercontent.com/shaurya35/solana-realtime-indexer/d7f510dcc36a3b7635d4bf89ea1e911e5eb8ed98/src/writer.rs)

**Limits/corrections.** This is the only actual live recorder of the four, but recordings are local files and the README says they are about 340 MB per two minutes. A restart does **not** resume from the stored checkpoint; README marks checkpoint reading at startup as planned. Reorg handling is also planned. Therefore “durable recorder” is only partly correct: captured files and database rows persist, but continuous restart-safe recording is absent. The checked-in 12-hour evidence is repository-supplied evidence, not an independent rerun. [README/status and evidence claims](https://raw.githubusercontent.com/shaurya35/solana-realtime-indexer/d7f510dcc36a3b7635d4bf89ea1e911e5eb8ed98/README.md) · [evidence index](https://raw.githubusercontent.com/shaurya35/solana-realtime-indexer/d7f510dcc36a3b7635d4bf89ea1e911e5eb8ed98/docs/evidence/README.md)

**Tests/CI.** Source contains ten tests, including database-dependent cases; CI provisions PostgreSQL and runs format, Clippy, and tests. The latest linked run passed, which runtime-proves that workflow at that commit—not live capture or the 12-hour claims. Local Rust tests were **not run** because this audit environment has no `cargo`. [workflow](https://raw.githubusercontent.com/shaurya35/solana-realtime-indexer/d7f510dcc36a3b7635d4bf89ea1e911e5eb8ed98/.github/workflows/ci.yml) · [successful run](https://github.com/shaurya35/solana-realtime-indexer/actions/runs/32726221123)

**Credentials/hygiene/free-only.** `.env.example` contains no secret and leaves `YELLOWSTONE_X_TOKEN` blank; `.env` is ignored. Live mode requires a personal token for the advertised gRPC endpoint and uses Solana public RPC. Solana states public RPC endpoints are rate-limited, so the live path is not proven no-meter/unbounded. The Docker fixture/API demo and offline replay/tests need no account, wallet, card, or paid package. [environment template](https://raw.githubusercontent.com/shaurya35/solana-realtime-indexer/d7f510dcc36a3b7635d4bf89ea1e911e5eb8ed98/.env.example) · [official Solana public-endpoint limits](https://solana.com/docs/references/clusters) · [Allnodes pricing/public-token page](https://www.allnodes.com/pricing)

## 2. `Solana-Trading-Lab/pump.fun.meter`

**Metadata/license.** Public, unarchived `main`; created 2026-06-25, pushed 2026-08-24; audit HEAD [`63b823d`](https://github.com/Solana-Trading-Lab/pump.fun.meter/commit/63b823d74397df8787e853f4570bb262ca92f3e3); 26 stars, 3 forks, 0 open issues; standard MIT file. [Repository API](https://api.github.com/repos/Solana-Trading-Lab/pump.fun.meter) · [tree API](https://api.github.com/repos/Solana-Trading-Lab/pump.fun.meter/git/trees/main?recursive=1) · [LICENSE](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/LICENSE)

**Broken package / false product metadata.** GitHub’s description advertises a real-time daily analytics dashboard, exact stats, Telegram alerts, and one-click 24/7 operation. The tree instead contains a TypeScript PumpAPI toolkit—no dashboard or Telegram code. The current `package.json` was reduced to only `ioredis-om-typed`, with no scripts, package metadata, or actual source dependencies; its lockfile describes a different old manifest. `npm ci` against npmjs failed during this audit (`ETARGET`, missing transitive `ioredis-typed@^1.0.128`), so current installation/build documentation is false. [package.json](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/package.json) · [stale lockfile](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/package-lock.json) · [README](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/README.md)

**Recorder/persistence/replay—source-observed.** There is no recorder. `StreamClient` receives/reconnects but never writes events. Replay downloads PumpAPI hourly `.jsonl.zst` files; persistence is limited to optional compressed archive caching and a generic JSON result cache. There is no mechanism to replay a recorded live stream. [stream client](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/src/stream/client.ts) · [archive downloader](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/src/replay/downloader.ts) · [result cache](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/src/storage/cache.ts)

**Tests/CI.** No tests, test script, workflow, workflow run, tag, or release exists. [workflow API](https://api.github.com/repos/Solana-Trading-Lab/pump.fun.meter/actions/workflows) · [runs API](https://api.github.com/repos/Solana-Trading-Lab/pump.fun.meter/actions/runs)

**Credential/supply-chain hygiene.** Trading calls send the user’s base58 Solana private key in JSON to `https://api.pumpapi.io`; source does not persist it locally, but “private key stays local” would be false. More seriously, `.env.example` base64-decodes to plaintext custom registry `http://212.193.3.61:4873/`; `.vscode/tasks.json` decodes and uses it in an install task configured to run on folder open. `.npmrc` expects `REGISTRY`, while the example defines `REGISTRY_STR`. Treat the repository as a supply-chain risk; do not run its folder-open task or use that registry. No actual committed wallet/API secret was observed in the current tree. [API client](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/src/pumpapi/client.ts) · [.env.example](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/.env.example) · [.npmrc](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/.npmrc) · [folder-open task](https://raw.githubusercontent.com/Solana-Trading-Lab/pump.fun.meter/63b823d74397df8787e853f4570bb262ca92f3e3/.vscode/tasks.json)

**Free-only.** **Fails.** Its own README and PumpAPI’s official fee page state trading costs 0.25% of volume and other operations require SOL/network/priority/Jito costs; this needs a funded wallet. PumpAPI labels data stream and historical replay free. During this audit a replay archive object returned HTTP 200 without credentials; the live WebSocket was reachable but closed with its one-connection-per-IP policy, so event delivery was not independently proven. ## 3. `yksanjo/pumpportal`

**Metadata/license.** Public, unarchived `main`; created 2026-05-11, pushed 2026-06-10; audit HEAD [`b1d8ad4`](https://github.com/yksanjo/pumpportal/commit/b1d8ad47f240846b0fb15e7fd79a985b21b1e0e8); 0 stars/forks/open issues; standard MIT file. **Tests/CI/runtime.** Nine unit tests cover config, scoring, and SQLite basics. Local audit execution passed `9 passed` (with a warning because `pytest-asyncio` was absent in the ambient environment). GitHub CI also passed on Python 3.10–3.12. Separately, an anonymous runtime probe subscribed to `wss://pumpportal.fun/api/data` and received a real token-creation event. Helius enrichment never populates holder/deployer concentration fields, and the accepted Bitquery key is unused; thus anti-rug, supply-concentration, and “analysis of any token” claims are materially overstated. The latest commit message mentions a `setup-node` bump although this Python repo uses `setup-python`. The core anonymous PumpPortal event stream was runtime-proven at audit time, and PumpPortal says WebSocket data has no charge; its current fees page also says trading data is available to API-key subscribers, which conflicts with the anonymous event observed and makes policy durability unclear. ## Bottom line

- For an actual local recorder plus replay, only **`solana-realtime-indexer`** implements both, but live capture is not restart-resumable and depends on external RPC/gRPC credentials/services.
- For no-wallet historical data, **`replayer-rust`** has the clearest narrow design, but lacks CI, a complete license distribution, and a replay reader for its own persisted tapes.
- **`pumpportal`** is a live explorer with summary persistence, not a recorder/replayer; several risk-analysis/UI claims do not match code.
- **Do not treat `pump.fun.meter` as installable or hygienic at current HEAD.** Its manifest is broken and its automatic custom-registry task is a serious supply-chain warning.
