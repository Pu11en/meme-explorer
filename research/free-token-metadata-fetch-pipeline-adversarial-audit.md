# Adversarial audit: strictly free Solana token-metadata fetch pipeline

**Audited candidate:** `research/free-token-metadata-fetch-pipeline-audit-2026-08-26.md`  
**Evidence:** owner-maintained documentation, specifications, repositories, and license files only.  
**Rule:** no card, funded wallet, account credits/CUs, paid trial, payment adapter, or undocumented endpoint/scraping. Self-hosted software may be license-free, but hardware, bandwidth, storage, and administration are not zero-cost.

## Verdict

The candidate is viable only as a **strict-free, anonymous, best-effort reader with integrity checks and safe failure**. It is not a robust production service. No reviewed primary source grants perpetual free capacity or an uptime SLA across Solana public RPC, public IPFS utilities, or public AR.IO/Arweave gateways. If “robust” means supported or contractual availability, status is **`not-reliably-solvable-free`**.

Mandatory corrections:

1. **Solana's published limits are changeable ceilings, not an entitlement.** The clusters page currently lists 100 requests/10 s/IP total, 40 requests/10 s/IP for one RPC method, 40 concurrent connections/IP, 40 connection attempts/10 s/IP, and 100 MB/30 s. Solana also says limits may change without notice, high-traffic applications may be blocked, and public endpoints are not intended for production ([clusters](https://solana.com/docs/references/clusters), [RPC guidance](https://solana.com/rpc)). Runtime rate-limit headers may differ; record them, but neither page values nor observed headers are reserved capacity.
2. **A Metaplex PDA is not universal Solana token metadata.** Token-2022 supports `MetadataPointer` and `TokenMetadata` extensions, including metadata on the mint or at another pointed account. A Metaplex-only reader must return `unsupported_metadata_standard`/`no_metaplex_account`, not “no token metadata” ([Solana extensions](https://solana.com/docs/tokens/extensions), [Token-2022 extension source](https://github.com/solana-program/token-2022/blob/main/program/src/extension/mod.rs)).
3. **Anonymous reachability is not a free entitlement or SLA.** Base public reads document no signup/key/wallet, but IP rate limiting, discretionary blocking, operator policies, and x402-capable gateways preclude any promise of perpetual, unlimited, supported free access.

## Correct status model

- `verified_metadata`: on-chain identity checks pass plus applicable CID/Arweave proof.
- `unverified_mutable_metadata`: bounded HTTP(S), IPNS/DNSLink, ArNS, or plain gateway bytes retained only as a timestamped observation.
- `no_metaplex_account`: PDA absent; **not** equivalent to no metadata.
- `unsupported_metadata_standard`: mint/program/extension layout not implemented.
- `transport_unavailable`: DNS/TLS/socket/timeout/5xx/endpoint-local 404.
- `rate_limited` / `blocked` / `payment_required`: preserve 429/403/402 separately.
- `proof_failed`: ID, signature, block multihash, traversal, size, data-root, or item proof failed.
- `unsafe_uri` / `too_large` / `invalid_json`: policy failure, not absence.

Never silently switch from strong verification to trusted headers/plain bytes, paid x402, or metered RPC/DAS.

## Required falsification tests

1. **Solana:** credential-free finalized reads; record status, JSON-RPC error, slot, latency, all rate headers, `Retry-After`. Controlled probes around documented thresholds must not bake observations into contracts. Inject 403/429/5xx/timeouts/stale slots; prove bounded jitter, circuit breaking, no retry storm.
2. **PDA/decoder:** golden vectors across official JS and independent derivation; mutate seed/order/program. Reject wrong PDA/owner/key/mint, truncation, malformed Borsh options, unknown layout; retain raw bytes/hash.
3. **Token-2022:** fixtures for metadata on mint, pointer to another account, no extension, invalid pointer, unknown TLV, and classic Metaplex. Absence in one path must trigger another supported path or explicit status.
4. **IPFS:** multi-block/path/range fixtures; missing child, corrupt CAR block, wrong root, malformed/truncated CAR, root CID differing from file SHA-256. Require completeness only for requested traversal. Test gateway conformance and operator independence separately.
5. **Kubo:** prove port 5001 is unreachable externally; test no provider/peer, unpinned data, routing outage, disk pressure, restart. Never label local daemon offline or zero-cost.
6. **Arweave L1/ANS-104:** known L1 and bundled item; flip payload/metadata/signature/tags and require hard failure. L1 verification alone must never accept an ANS-104 item.
7. **Wayfinder:** assert signature strategy at startup. Remote headers, trusted-reference hash, disabled/unknown verification cannot yield `verified_metadata`. Inject network/5xx versus 402/429/404 and prove explicit free-only gateway rotation without lowering verification.
8. **Zero-spend invariant:** no x402 wrapper, wallet/private key, payment headers, settle call, or balance change. On 402 record `payment_required`; rotate/defer only.
9. **Availability:** 7–30 day canary from deployment egress measuring verified success, 402/403/429, failures, p95/p99, stale slots, operator-correlated outages. Passing is empirical, never an SLA.
10. **License gate:** archive each pinned artifact's manifest, licenses/notices, source tag/commit, checksum; CI fails on missing/changed/ambiguous terms. Legal review for Metaplex Rust and AGPL deployment.

## Corrected final claim

> A no-account/no-wallet/no-credit **best-effort** reader can use Solana public RPC, local classic-Metaplex and Token-2022 decoding, CID-verifying IPFS retrieval, and explicitly configured signature-verifying Arweave retrieval. It can provide strong integrity and explicit failure while anonymous capacity is available. The reviewed sources grant neither stable free quotas nor independent RPC quorum, complete content availability, or production SLA; therefore a strictly free **robust/contractually reliable** pipeline is not established.
