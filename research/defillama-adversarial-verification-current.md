# DeFiLlama Coins API — corrected adversarial verification

**Evidence cutoff:** 2026-08-26 UTC. **Strict verdict: REJECT** as the required new-Pump chart source and as a commercial production dependency absent written permission and explicit quota, cadence, SLA, and Pump-coverage commitments.

## Corrected findings

1. **Chart bounds were previously overstated.** The official free [OpenAPI](https://github.com/DefiLlama/api-docs/blob/main/defillama-openapi-free.json) lists both `start` and `end` as optional `/chart/{coins}` parameters, but the owner endpoint rejects supplying them together: a bounded live request returned HTTP 400 with `{"message":"use either start or end parameter, not both"}`. The operative behavior is therefore **`start` OR `end`, not a caller-bounded start-to-end range**. `span` and `period` control the returned series around the selected boundary; clients must not generate requests containing both bounds.

2. **Anonymous reachability does not prove unmetered access.** Wrapped-SOL current, historical, and chart calls worked without an account, key, cookie, or authorization header, consistent with the official [SDK free-tier configuration](https://github.com/DefiLlama/api-sdk#quick-start). That proves only observed no-account access. The owner documentation says Pro receives “higher rate limits,” while publishing no exact anonymous ceiling, window, burst rule, accounting scope, or quota headers in the reviewed contract ([free OpenAPI](https://github.com/DefiLlama/api-docs/blob/main/defillama-openapi-free.json)). **Undisclosed server-side or per-IP metering remains possible and is not ruled out by successful anonymous probes.** Consequently this candidate does not satisfy a strict requirement for documented non-metered service.

3. **Coverage remains too sparse for new Pump assets.** Pump’s official [program documentation](https://github.com/pump-fun/pump-public-docs/blob/main/docs/PUMP_PROGRAM_README.md) and [IDL](https://github.com/pump-fun/pump-public-docs/blob/main/idl/pump.json) establish immediate bonding-curve creation/trading semantics. Nevertheless, bounded exact-mint DeFiLlama requests returned HTTP 200 with `{"coins":{}}` for a finalized fresh `create_v2` mint and for an active bonding-curve mint. This proves that valid, tradeable Pump assets are not guaranteed immediate—or any committed—Coins coverage. Empty maps mean “not returned in this request/cache snapshot,” not nonexistence or price zero.

4. **Independence from PumpAPI is unverified.** DeFiLlama’s [OpenAPI price description and schemas](https://github.com/DefiLlama/api-docs/blob/main/defillama-openapi-free.json) provide only a global source hierarchy and per-coin price/timestamp/symbol/confidence data; chart points contain only `timestamp` and `price`. They do not identify a contributing provider, DEX, pool, quote, trade signature, slot, block, or finality. PumpAPI separately documents Pump-family stream events and derived price/reserve fields ([Data Stream](https://pumpapi.io/stream)). Because DeFiLlama supplies no per-point provenance, **PumpAPI duplication or overlap through the same upstream trades, pools, adapters, or aggregators cannot be excluded**. DeFiLlama charts must not be counted as independent corroboration merely because they come from a different HTTP provider.

5. **Operational and legal guarantees remain absent.** No indexing-delay, update-cadence, retention, uptime, or availability SLA was found. Cache directives observed on chart responses are transport behavior, not an ingestion promise. DefiLlama’s owner [Terms of Use](https://defillama.com/terms) cover its public APIs, describe service/data as provided as-is/as-available, and restrict commercial exploitation, republishing, and resale absent permission.

## Disposition

Use DeFiLlama only as removable, failure-tolerant enrichment for established assets, preserving returned timestamps and explicit missingness. **Strict verdict remains REJECT** for new-Pump chart truth, independently corroborated Pump coverage, documented non-metered access, or commercial production reliance without written provider commitments.
